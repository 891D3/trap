以 mygo 桌面应用为宿主——Go 侧实现工作流执行引擎（DAG 调度器 + 节点状态机 + 本地子进程执行器 + 事件日志落盘），通过 mygo 插件机制（RPC + WebSocket 事件流）把引擎暴露给 WebView 前端；前端用 React + React Flow 渲染 DAG 画布，实时高亮当前执行路径、展示统计与审批卡点，可在画布上点击放行，所有数据为本地文件，存放在Sqlite。

个人工作台：在桌面上一直打开的，能够实时看到的页面，数字化工作台，快速迭代功能来支持的个人工作、学习及兴趣爱好而开发的一个平台

整体布局是三栏布局，左侧是侧边导航栏区域，中间是主功能操作区域，右侧是辅助区域。
左侧导航栏区域：可以收起/展开，从上到下是用户信息区、工作台功能区、项目列表区和设置
顶部第一行区域：首先是圆形头像，用来表示当前用户的身份标示，头像右侧是用户姓名+“的工作台”字样
第二行区域：功能菜单区域，比如待办事项、信息记录和快捷入口
第三行区域：项目列表
最底下是设置按钮

中间主功能区域：待办列表、数据看板（占 65% - 80% 宽度）
待办列表：可以记事，能快速加待办，点一下打勾完成，能删掉
信息记录：灵感、重要事项等，归集后可以整理成markdown本地数据
项目工作：项目的进度、分类事项的明细内容
快捷入口：一些工具、网站等的汇总信息，方便快速跳转到目标地址，执行添加、删除和修改

辅助区域：日历、快捷便签、动态消息流（占 20% 左右宽度）
