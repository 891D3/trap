# 2026-10-17 热点资讯接入 + 版本号规则 + 复测修复收尾

## 做了什么

- **农历不显示修复**：WKWebView ICU 的 `Intl.DateTimeFormat` day 部分直接返回中文序数（「初八」），与 node full-icu 返回数字不同；`Number('初八')=NaN` 导致 `lunarOf` 返回 null。`web/src/api/lunar.ts` 兼容两种形态。教训：验证前端 ICU 行为必须用真实 WKWebView（swift evaluateJavaScript 探针），不能只信 node。
- **热点资讯功能**（commit cd4c96a）：`internal/service/news.go` NewsService——news.orz.ai 聚合接口，内存缓存 TTL 10 分钟、启动预热 + 定时后台刷新（ctx 可取消 goroutine）、手动刷新 `Fetch(platform, force)`、失败降级返回缓存；`news.changed` 事件广播。前端 `web/src/api/news.ts` + `realtime/news-events.ts` + DashboardView 标签页（懒加载、榜单前三红色序号、手动刷新按钮 IconRefresh）。
- **渠道调整**：微博 → 腾讯网（tenxunwang），新增 douyin/eastmoney/xueqiu，四渠道均真实连通验证（51/51/20/10 条）。
- **侧栏版本号**：`AppService.Version()` 返回 appVersion，store 启动加载一次，侧栏底部设置行右侧弱化展示。
- **版本号规则**（commit 1565333）：`v<base>-<git短hash>`，`scripts/build.sh` 构建时临时注入 mygo.config.ts 与 app.go，构建后还原（版本号不入库）。产物如 `Trap 0.3.1-dee3b82 arm64.dmg`。
- **今日信息卡调整**（2e70435/0427af6/aea63ce）：待办内容与侧栏「待办事项」重复 → 取消 todayAgenda 时间轴展示，「今日信息」仅作标题（改卡片标题样式 + cursor: default），底部「项目进行中」保留；资讯渠道 tab 不变。
- **E2E 修复**：设置按钮定位改 `.side-label`（按钮内加版本号后整按钮 textContent 不再精确等于「设置」）。

## 为什么这样做（含被否决的备选方案）

- 编译 code 用 git 短 hash 而非手工递增计数：自动、可追溯、零维护。
- 新闻缓存放内存而非 SQLite：热点榜单属易失数据，崩溃后重拉即可，不值得入库；符合本地化约束（仅访问用户配置渠道源，无用户数据上传）。
- 「今日信息」保留 tab 形式仅去掉内容：渠道 tab 已成型，改为纯卡片标题会让 tab 结构破碎；用户确认此方案。
