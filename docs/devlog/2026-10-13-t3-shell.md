# 2026-10-13 T3 三栏壳（壳优先）

## 做了什么

- React 接入：`react`/`react-dom` + `@types/*` + `@vitejs/plugin-react`（vite.config.ts 加插件，PRD 已确认依赖）；入口 `web/src/main.tsx` 挂载 `#root`，`web/index.html` 指向 main.tsx。
- 设计令牌落地 `web/src/styles/tokens.css`：ui-baseline 全部令牌（#F6F7F9 底/#4F6BF6 主色/圆角 16、20/阴影/动效 ease-out + 文字延迟 80ms + 微动效 150–200ms）；主题 `useTheme` 解析 system/light/dark → `<html data-theme>`（localStorage 持久化），浅/深两套变量。
- 三栏壳：
  - `Sidebar`：悬浮岛式（外边距 16、圆角 20、柔和阴影），240px ↔ 72px 收起，收起态悬停临时展开覆盖中栏（不挤布局），文字延迟 80ms 淡入；用户信息区/功能菜单（激活态主色底衬）/项目占位（置灰「项目（M1 开放）」）/设置+收起按钮固定底部。
  - `MainArea`：标题区（20px 标题 + 13px 说明随视图切换）+「今日完成」实数据卡（唯一视觉锚点，M0 口径）+ 视图切换容器。
  - `Auxiliary`：右栏三块占位卡（半透明底/1px 描边、无投影、低视觉权重，标注 M1 开放）。
- 四视图骨架（mock 数据集中在 `state/app-store.tsx`，T2 后替换为服务调用）：
  - `TodoView`：输入回车即加、自定义复选框勾选动效（文字变灰+删除线）、已完成沉底+分组计数、悬停显示删除（ConfirmDialog 二次确认）；
  - `NoteView`：全部/已归档筛选、卡片流、归档/删除、整理导出按钮占位禁用（T2 接入）；
  - `LinkView`：卡片网格（首字母彩色头像）、添加入口 InputDialog（名称/URL/分组）、删除确认；跳转 Open 待 T2；
  - `SettingsView`：姓名可改（同步左栏）、主题三档可用、数据目录/导出目录/AI/更新占位禁用。
- 响应式（ui-baseline 通用规则）：<1200px 右栏折叠为抽屉（含遮罩）、侧栏强制收起态（悬停可展开）。

## 为什么这样做（含被否决的备选方案）

- mock 状态收敛在 `app-store.tsx` 单文件 + Context：T2 接真数据时只改这一层，视图组件不动（符合「组件纯展示、状态由 store 驱动」）。
- 收起态悬停展开用「wrapper 保持 72px + panel 绝对定位扩展」而非宽度动画挤占 flex：避免中栏布局跳动。
- 不引入图标库：手写 14 个内联 SVG 足够 M0（避免未确认依赖）；首字母彩色头像替代 favicon（ui-baseline 映射决策）。
- 被否决：引入 zustand/组件库（M0 体量不需要）；收起态悬停不做覆盖动画（设计稿明确要求平滑展开）。
