# 2026-10-15 R3 壳重构 v3（侧边栏/顶栏/辅助区）

## 做了什么

（分支 `feature/r3-shell`，基于 R2）按 ui-baseline v3 §二重构应用壳并接通项目实体：

- **Sidebar 重写**：用户信息区（头像44 + 姓名 + 「个人工作台」副标 + 收起按钮移到顶部）；「工作台」分组下 5 个菜单项（数据看板/待办事项/信息记录/股票看台占位/快捷入口），active = 左侧 3px 主色指示条（CSS ::before，删除色块高亮）；待办项带未完成数字角标（>99 显示 99+）；项目列表区：标题行（项目 + 新建按钮）、项目行（色点点用 `--proj-*` 令牌 + 名称 + 未完成计数）、每行 hover 出「编辑」按钮；底部设置。
- **项目弹层**：新建/重命名共用 CustomDialog（名称输入 + 四色色盘），编辑态内含「删除项目…」（ConfirmDialog 明示「待办保留、关联置空」）。删除经由 store 走真实 IPC。
- **Topbar 新组件**：64px 白底；页面标题 16 Bold + 面包屑 11；全局搜索框 280×36（样式占位，禁用输入，PRD v2.0 范围外说明）；操作组 = 通知（红点占位）/筛选（占位）/主题切换按钮（循环 system→light→dark，图标随态，标题提示当前模式）。v1 的右上「辅助区」抽屉开关按钮随 MainArea 头部一起移除（窄屏深链接抽屉逻辑保留在 App）。
- **MainArea 简化**：`.main` 成为顶栏 + 内容区两段；v1 的独立标题说明、右侧「辅助区」切换按钮、「今日完成」stat 卡（段内 v1 遗留）一并移除。
- **Auxiliary 改为随视图映射**（props view）：todo → 月历/按属性看占位卡（R5 充实）；其他视图 → 今日聚焦/最近记录占位卡（R4 充实）；设置页不渲染。
- **默认视图改为数据看板**（PRD 拟定决策 1；深链接 `e2eView` 仍可用）；新增 StockView 占位页。
- **app-store 扩展**：projects 状态（list/add/edit/delete）+ `project.changed` 订阅（deleted 时同时重拉待办、清空指向该项目的过滤态）；新增 `projectFilter/openProject/clearProjectFilter`（点击侧栏项目→待办视图过滤态，R5 待办视图消费）；ViewId 增加 `stock`。
- **E2E 更新**（共 4 处断言适配）：布局约定改为「看板与待办均有辅助区、设置无辅助区、默认视图=数据看板顶栏标题数据看板」；设置流程三处 `querySelector('input')`/`setInputAndBlur(page, 'input')` 改为 `input[aria-label="姓名"]`（顶栏搜索输入框在 DOM 序上先于姓名框，通配选择器不再指向它，已在姓名输入上加 aria-label）；`reloadToTodo`/`reloadAndWait` 适配默认视图变化（显式 `e2eView=todo` / 等导航条出现）；clickNoteCard 前补「等记录列表加载」等待（列表异步，原来靠时序运气）。

## 为什么这样做（含被否决的备选方案）

- 收起按钮从底部移到用户信息区右侧：设计稿（2:636 用户信息区含收起钮）与 v1 不同，按 v3 为准。底部「切换」按钮删除，避免双入口状态打架。
- 主题切换循环顺序 system→light→dark 而非弹下拉：M0 无下拉组件实现负担最小，且与设置页 seg-btn 语义一致（同一 store 状态源）。
- 顶栏搜索输入 `disabled`：PRD 范围外注明「仅样式占位」；禁用可避免 E2E 与真实焦点冲突（设置流程改名了选择器，但保守起见仍禁用）。
- E2E `clickNoteCard` 等待列表加载被否决的备选：在 clickNoteCard 内做长轮询重试——直接复用 waitFor 机制更简单且语义相同。
- 项目编辑用 hover 出的「···」而非右键菜单：WKWebView 无右键约定，触摸/无鼠标场景更稳。
- 未在 R3 消费 projectFilter 到待办视图（避免半成品过滤逻辑），交给 R5 一并验收。
