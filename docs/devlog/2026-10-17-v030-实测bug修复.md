## 为什么这样做（含被否决的备选方案）

- **复现测试路线**：repo 无前端单测框架（无 vitest），AGENTS.md 禁止未经确认引新依赖 → 全部走 E2E（`runTodoV2Flow` 此前已定义但**从未接入主链**，本次接入后这些流程首次被真实验证）。否决了「引入 vitest 写纯函数单测」。
- **pickProject token 替换语义**：最初实现「# 到光标」替换，E2E 揭示会把 token 后的正文一并吞掉（title 剥离后为空 → 「待办内容不能为空」）；改为与 `projectQuery` 同语义的「# 到其后第一个空白/行尾」。
- **projectQuery 语义**：E2E 揭示「光标处 token 含空白即 null」会让已打完 token 的场景浮层消失；放宽为「光标仍在 # 所在行之后即保持联想」。
- **due_date 存储格式**：实际存储为毫秒格式 `2026-10-18T07:00:00.000Z`，E2E 断言按此适配（`internal/store/conv.go timeRFC3339` 上游用 `toISOString()`）。
- **#10 存量脏数据**：渲染端已判空，但已入库的 `category='work'` 兜底数据不自动清洗（堵住编辑态兜底入口即可）；待用户确认是否手动改。
