# 2026-10-14 配置 Ardot 云端 MCP

## 做了什么

- 使用 Pi 全局 MCP 配置命令新增服务 `ardot-remote`。
- 地址为 `https://ardot.tencent.com/mcp`；Pi 根据 `url` 将其识别为 streamable HTTP（HTTP 类型）。
- 配置写入 `~/.pi/agent/mcp.json`，未写入项目级 `.pi/mcp.json`，因此对当前用户的 Pi 会话生效。

## 为什么这样做（含被否决的备选方案）

- 采用 Pi 内置的 `pi mcp add`，避免手工破坏现有 MCP 配置；未配置 bearer token，因为用户未提供凭据，且服务支持 OAuth 登录流程。
- 未自动执行 OAuth 登录，避免代替用户进行外部账户授权；待用户确认后通过 `pi mcp login ardot-remote` 完成。

## 验证结果（跑了哪些测试、结果如何）

- `pi mcp list` 能读取并连接配置，结果为 `ardot-remote: needs sign-in (codemode, global)`，说明地址与配置格式有效，但尚未完成 OAuth。

## 遗留问题 / TODO

- 用户需按 Pi 的 OAuth 流程运行 `pi mcp login ardot-remote`，在浏览器中完成授权；授权完成后重新运行 `pi mcp list` 或在当前 Pi 会话执行 `/reload`。
