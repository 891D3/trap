## 一、设计提示词（原文，未删改）

【页面整体】
页面底色使用柔和的浅灰白（如 #F6F7F9），禁止纯白贴满；三栏之间不做贴边硬分割，
靠留白和层次区分。中间主功能区占 65%~80% 宽度，右侧辅助区占 20% 左右宽度，
剩余宽度给左侧导航。整体风格干净、克制，避免模板感。

═══════════════════════════════════════
【左栏 · 侧边导航栏】（宽 240px，可收起/展开）
═══════════════════════════════════════
- 栏体形态：悬浮岛式设计——脱离屏幕左缘，四周留 16px 外边距，圆角 20，
  衬一层低透明度的柔和阴影，页面底色从四周透出来。
- 收起/展开：点击底部或顶部的收起按钮，宽度从 240px 平滑过渡到 72px
  （只保留图标），悬停时平滑展开回 240px；文字延迟 80ms 淡入，
  缓动曲线用 ease-out。
- 从上到下依次为四个区域：

  ① 用户信息区（顶部）
     - 圆形头像（44px，带 2px 主色描边或浅色圆环），表示当前用户身份；
     - 头像右侧两行文字：用户姓名（15px 加粗）+「的工作台」（12px 灰色）。

  ② 功能菜单区
     - 三个功能项：待办事项、信息记录、快捷入口；
     - 每项 = 图标 + 文字（15px），常规态低饱和浅灰文字，
       激活态使用高亮强调色（主色 #4F6BF6）+ 浅色圆角底衬；
     - 点击切换中间主功能区的对应视图。

  ③ 项目列表区
     - 组标题「项目」用 11px 大写灰字标在上方；
     - 列出项目项（图标/色点 + 项目名），点击进入项目工作视图；
     - 项目数超过可视高度时此区域单独滚动，支持「+ 新建项目」入口。

  ④ 设置按钮（最底部，固定不随列表滚动）
     - 图标 + 「设置」文字，与上方区域之间用细分隔线或留白隔开。

═══════════════════════════════════════
【中栏 · 主功能操作区】（自适应，占 65%~80%，左右各留 32px 内边距）
═══════════════════════════════════════
- 顶部为页面标题区：20px 加粗标题（随当前视图切换）+ 一行 13px 灰色说明文字。
- 顶部下方为数据看板横条：2~4 张统计卡片（圆角 16、纯白底、极淡阴影、
  卡片间距 24px），主数值 28px 加粗、辅助文字 13px 灰色，
  展示今日待办完成数、项目进度概览等信息。
- 看板下方为主工作视图，随左侧功能菜单切换，共四种：

  ① 待办列表视图
     - 顶部输入框：支持快速添加待办（回车即加）；
     - 列表项 = 自定义复选框 + 待办文字（15px）+ 删除按钮（悬停显示）；
     - 点击复选框打勾完成：文字变灰 + 删除线 + 平滑勾选动效；
     - 已完成项沉底或折叠显示。

  ② 信息记录视图
     - 顶部输入区：快速记录灵感、重要事项（支持标签分类，如「灵感/重要/待整理」）；
     - 卡片流或列表展示记录，按标签筛选；
     - 「整理导出」按钮：将选中的记录归集、按时间/标签整理成 Markdown
       并下载保存到本地（文件名含日期）。

  ③ 项目工作视图
     - 顶部：项目标题 + 整体进度条（主色，圆角）；
     - 主体：分类事项明细——按分类分组的任务列表（复用待办的勾选交互），
       每组标题旁显示「已完成/总数」；
     - 支持查看单个事项的详情（右侧滑出或行内展开）。

  ④ 快捷入口视图
     - 卡片网格（每行 3~4 个）：每个入口 = 网站/工具图标 + 名称 + 域名小字，
       点击新标签页跳转目标地址；
     - 支持「添加入口」（弹窗填名称 + URL，图标自动取 favicon）、
       悬停显示编辑/删除按钮。

═══════════════════════════════════════
【右栏 · 辅助区域】（宽 20% 左右，约 300~320px）
═══════════════════════════════════════
- 视觉层级低于中栏：使用半透明浅底卡片或与页面同底色的 1px 浅灰描边卡片，
  不加投影，与中栏白色实底卡片形成前后层次；块间距 24px，内容可单独滚动。
- 从上到下三个信息块，每块标题 14px 加粗：

  ① 日历：当月月历视图，今日高亮（主色圆点/圆环），有待办的日期标小点；
     点击某日可快速查看/新增当日待办。

  ② 快捷便签：多张彩色小便签（米黄/浅蓝/浅绿，圆角 8，轻微旋转 0.5~1°
     增加手写感），支持点击添加、双击编辑、右上角删除。

  ③ 动态消息流：按时间倒序的活动流（如「完成了待办 xx」「新建了项目 yy」，
     时间 12px 灰色），每条带小图标，最多显示 20 条。

【通用规则】
- 视觉重量分配：全页只允许一个视觉锚点（侧边导航激活态或看板主数值），
  其余元素一律降低对比度；右栏整体视觉权重必须低于中栏。
- 动效：卡片和面板进场使用 ease-out 缓动；宽度/高度过渡先行，
  文字延迟 80ms 淡入；待办勾选、便签增删都做 150~200ms 微动效。
- 响应式：窗口宽度不足 1200px 时右栏折叠为抽屉；侧边栏窄屏自动收起为 72px。
