## 一、设计原则（设计稿 Section 01）

1. 数据优先：数字与文字是第一视觉，装饰一律让位。
2. 克制的色彩：80% 界面只用中性色；主色只出现在动作与选中态；语义色只表达涨跌/状态（**涨红跌绿，遵循中国金融市场惯例**）。
3. 层级用间距与灰度，不滥用分割线与阴影。
4. 阅读路径从左到右：导航 → 内容 → 辅助。

## 二、布局骨架（Section 05 + 两张功能页实测）

```
┌──────────┬──────────────────────────────────┬─────────┐
│ 侧边导航  │ 顶栏 Topbar（64px，白色）         │ 辅助区   │
│ 216px    ├──────────────────────────────────┤ 256px   │
│ 白色     │ 主内容区（底色 #F4F4F5，p12/g12）  │ 白色    │
│ 可收起64 │  卡片（白底 r16）网格             │ 可收起  │
└──────────┴──────────────────────────────────┴─────────┘
```

- **窗口**：最小 1024×680，默认 1440×900；<1200px 侧边栏自动折叠、右栏折叠为抽屉。
- **侧边导航栏（216px，可折叠至 64px）**，自上而下：
  1. **用户信息区**：头像 44 圆形 + 姓名（14 Bold #18181B）+「个人工作台」（11 Regular #71717A）+ 收起按钮（28×28 r8 灰底，hover 加深）；
  2. **分组标题**：「工作台」11px #A1A1AA，左右 padding 12；
  3. **菜单项**（高 36，r8，图标 18 + 文字 13，gap 10，左右 padding 12）：
     - `数据看板`、`待办事项`、`信息记录`、`股票看台`、`快捷入口`；
     - **active 态**：左侧 3px 主色指示条（r999，20 高）+ 文字/图标 #566C8C 13 Bold；**禁止用圆角色块做选中高亮**；
     - hover：文字加深 #18181B，无底色；
     - **待办事项带数字角标**：主色底白字全圆角 pill（20×18，10 Semi Bold），超 99 显示 99+；
  4. **项目列表区**（可独立滚动）：标题行「项目」（11 #A1A1AA）+「+」按钮（20×20 r6 灰底）；
     - 项目项（高 32，r8，左右 padding 12，gap 8）：色点 8×8 圆形 + 项目名 12 Regular #3F3F46 + 右侧计数 11 #A1A1AA；
     - 项目色从主色/语义色梯度分配（实测：蓝灰 #566C8C / 琥珀 #D97706 / 绿 #16A34A / 紫 #7C3AED）；
  5. **侧边栏底部**：设置项（高 36，同菜单样式）。
- **顶栏（64px，白底）**：页面标题组（16 Bold #18181B + 面包屑 11 #A1A1AA「个人工作台 / 页面名」）→ 全局搜索框（280×36，r8，#F4F4F5 底，图标 16 + 占位「搜索待办、记录、项目…」12 #A1A1AA）→ 操作组（通知 36×36 灰底 r8 + 8px 红点 #DC2626；筛选按钮；主题切换月亮按钮）。顶栏图标按钮规格：36×36 r8 #F4F4F5 底，图标 18px 1.5px 描边。
- **主内容区**：底色 #F4F4F5，padding 12（底部 0），卡片间距 g12。
- **辅助区（256px，白底，可收起，收起后主区扩展）**：内容随当前视图变化（Dashboard 映射 A、待办映射 B，见 §五）。

**Surface 深浅双模式（同一 token 双值，切换只换值不换结构）：**

| Token | Light | Dark |
| --- | --- | --- |
| 页面底 Background | `#F5F5F7` | `#101012` |
| 卡片 Card | `#FFFFFF` | `#1C1C1F` |

- 模式规则：默认跟随系统 appearance，支持手动覆盖并持久化；深色下语义色提亮一档（上涨 `#F87171` / 下跌 `#4ADE80`）。
- 浅色以阴影分层；深色阴影减弱、改用 1px 边框 `#2A2A2E` 分层。

### 字体排印

- **字体族**：不嵌字体文件；西文与数字走系统栈（Inter 优先），中文 PingFang SC（macOS）/微软雅黑（Windows 回退）；数字使用 tabular-nums 等宽对齐。
- **字号阶梯**（层级由字号+字重+灰度共同控制）：

| 阶梯 | 规格 | 用途 |
| --- | --- | --- |
| Display | 32/40 Bold | KPI 大数字、页面主标题 |
| Title | 16/24 SemiBold | 卡片标题、分区标题 |
| Body | 14/22 Regular | 正文、表格内容 |
| Label | 12/18 Medium | 表单标签、辅助说明 |
| Caption | 11/16 Regular | 图表轴标签、时间戳 |

（功能页实测补充：导航 13、侧栏项目名 12、列表项目标题 13、分组节标 11、徽章 11 Medium、页脚/说明注 10–11。）

### 间距 / 圆角 / 阴影

- **间距**：4px 基数，只取 4 / 8 / 16 / 24 / 32（图标与文字 4，组内 8，卡内分区 16，卡片网格 24，页面级 32）；禁中间值。
- **圆角**：sm 4（徽章/标签/复选框 4 或 9 例外待定，实测复选框 r4）、md 8（按钮/输入框/导航项/日期块）、lg 12（小卡/浮层）、xl 16（主卡片/弹层）；pill 用 999。
- **阴影**：Card 静息 `0 1 3 / 4%`；Hover `0 4 12 / 8%`；Popover `0 8 24 / 12%`；深色模式减淡。

## 四、组件规范（Section 06，实测与功能页一致）

- **Button**（高 36 · r8 · 字 13/500，每屏只有一个 Primary）：
  - Primary：#566C8C，hover #47596F，disabled #F4F4F5/#A1A1AA；
  - Secondary：白底 1px #E4E4E7，hover 边框加深 #D4D4D8；
  - Ghost：无底无框字 #52525B，hover 底 #F4F4F5；
  - Danger：#DC2626，hover #B91C1C，破坏性操作二次确认。
- **输入框**：高 36 · r8 · 白底 1px 边框；标签 12/500 在框上方间距 6；错误 11px 红字在框下方，失焦即校验；提交中按钮 loading 不弹 toast。
- **导航项 / 徽章 / 角标**：见 §二；徽章全圆角高 20–22 · 浅底深字。
- **KPI 统计卡**（数据看板第一视觉层，一行 4 等宽 g12）：白底 r16 · padding 20/16 · 结构 = 标题（12 #71717A）+ 数值行 + 环比行（辅助灰 10–12 + 左右箭头徽章，红涨绿跌）+ 迷你趋势柱（无轴无标签，主色蓝灰梯度 r4）。
- **复选框**：16×16 r4；已完成主色底白勾，完成项文字 #A1A1AA + 删除线。
- **表格**（后续功能用）：表头 44px #FAFAFA 底 · 行高 52 · 数字右对齐 tabular · hover 整行 #FAFAFA；空态插图+引导；加载骨架屏（灰呼吸块，不转圈）。
- **图标**：24px 画布 · 1.5px 描边 · 圆角线帽 · 线性；默认 #52525B，激活 #384858 或主色；禁 emoji，同一语义只用一种图形。

## 六、图表规范（M2 数据看板启用）

## 七、响应式与动效

- <1200px：侧栏自动折叠 64、右栏折叠为抽屉；<1024px 禁止低于最小窗口。
- 动效：宽度/高度过渡 eased-out 先行，文字延迟 80ms 淡入；勾选/增删 150–200ms；卡片进场 ease-out。
